# Historical ChangeDocs

Everything in this directory is a historical ChangeDoc: a record of past changes,
designs, proposals, source analysis or verification. These files are not maintained
and must not be treated as descriptions of current behavior or active instructions.
This applies even when a file calls itself current, accepted, a requirement or a
maintenance guide.

Use the [LivingDoc](../stories/README.md) for product and developer needs and the
[root agent instructions](../../AGENTS.md) for current working rules and processes.

Read the archive when investigating history. Do not copy a historical statement
into an implementation decision without evidence of an explicit agreement in the
development conversation. Code inspection alone does not establish that agreement.

Preserve historical content. Link repairs and explicit archival notes are allowed;
do not update these snapshots to match current code. Scripts and templates here are
historical tools, not supported build or verification entry points.
