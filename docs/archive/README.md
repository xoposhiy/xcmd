# Documentation archive

The former contents of `docs` were archived on 2026-11-17. These ChangeDocs preserve
past requirements, proposals, implementation descriptions, source maps and evidence.
They are not maintained and do not describe the current product by authority.

- Read the [LivingDoc](../stories/README.md) for product and developer needs.
- Follow [AGENTS.md](../../AGENTS.md) and its process links for current work.
- Use the [historical source map](product-map/README.md) only as evidence about its
  reviewed snapshot. Its tools are archived too.
- The [ID migration record](product-map/id-migration.json) records the one-time
  move from numbered IDs to semantic IDs. It is not a second story catalogue.
- The [issue tracker description](issue-tracker.md) preserves the former
  `issues/README.md`; the active workflow is in `docs/processes/feedback.md`.

The initial LivingDoc migration retained 88 stories, removed implementation-specific
wording where it obscured a need, and added four developer stories for existing
headless verification, integration checks, quality checks and code-health reports.
Recovery of implementation decisions from past coding conversations was deferred.

Relative links to repository files were adjusted for the move. Commands, source
paths in prose, snapshot hashes and test results retain their historical meaning.
Some evidence points to local generated artifacts that may no longer be present.
