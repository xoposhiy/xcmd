Эта пачка позволит выполнять в Xcmd обычный сценарий целиком: выбрать файлы → скопировать или перенести → разрешить совпадения → убрать ненужное.

> Предлагаю такие истории, в порядке реализации:
>
> | Use cases | User story | Expected behavior |
> |---|---|---|
> | UC04 | As a user, I want to copy selected files and folders to the other panel so I can transfer a complete directory tree. | F5 copies nested files and empty folders. |
> | UC34 | As a user, I want to resolve name conflicts so I can keep the version I need. | Show source and destination details. Offer Skip, Rename and Replace, with an explicit apply-to-all choice. |
> | UC33 | As a user, I want long operations to run in the background so I can keep using both panels. | Run one operation at a time, queue later requests, and show progress. Capture source and destination when each request starts. |
> | UC33 | As a user, I want to cancel an operation and understand its result so I can decide what to do next. | Show completed, skipped, failed and cancelled items. Keep partial results clear. |
> | UC05 | As a user, I want to move selected files and folders so I can organize files between directories and drives. | F6 moves items. For cross-drive moves, remove each source only after its copy succeeds. |
> | UC35 | As a user, I want to delete selected items through the Recycle Bin so I can recover an accidental deletion. | Propose F8/Delete for recycling and Shift+Delete for permanent deletion, with distinct confirmations. |
>
