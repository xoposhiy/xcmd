### Codex final reply

> Сделал **виртуальную файловую систему внутри Xcmd**, с извлечением отдельных файлов по необходимости. При обычном входе архив целиком на диск не распаковывается.
>
> **Вход и переходы по папкам.** Xcmd читает каталог записей архива и хранит его в памяти: имена, пути, размеры, даты и другие доступные свойства. Панель получает из него список текущей папки. Путь состоит из пути самого архива и пути записи внутри него. Это внутренний механизм Xcmd, без монтирования диска в Windows.
>
> **F5 работает через существующую очередь копирования.**
>
> 1. Очередь обходит выбранные виртуальные папки и файлы.
> 2. Для каждого файла открывается поток распаковки из архива.
> 3. Данные записываются во временный файл **рядом с конечным файлом назначения**.
> 4. После успешного чтения временный файл получает конечное имя.
>
> То есть промежуточной распаковки всего выбранного дерева в `%TEMP%` здесь нет. Сохраняются обычные конфликты Skip/Rename/Replace, прогресс и отмена. При ошибке текущий временный файл удаляется; уже извлечённые файлы остаются.
>
> **F3 устроен немного иначе.**
>
> - На самом архиве создаётся текстовый отчёт с информацией и списком записей.
> - Для просмотра файла внутри архива этот конкретный файл сначала извлекается во временный кэш, затем открывается существующим просмотрщиком.
> - При входе во **вложенный архив** во временный кэш извлекается сам вложенный архив. Дальше его содержимое снова показывается виртуально.
>
> Кэш находится в `%TEMP%\Xcmd\archives-…`, повторно используется в течение сеанса; при закрытии предусмотрена очистка. Для временного открытия действует лимит **256 МиБ на файл**. У непосредственного извлечения по F5 этого лимита нет.
>
> Есть существенная особенность производительности: **виртуальное представление не означает произвольного доступа ко всем форматам**. ZIP обычно позволяет быстро получить отдельную запись. Для TAR.GZ или solid-архива библиотеке может потребоваться распаковать предшествующие данные. Сейчас каждый извлекаемый файл открывается отдельно, поэтому массовое извлечение таких архивов может повторять эту работу. Последовательная распаковка всей выбранной пачки за один проход — ещё не реализованная оптимизация.
>
> Запись внутрь архива пока закрыта: F5 извлекает наружу, а перенос, удаление и переименование записей запрещены.
