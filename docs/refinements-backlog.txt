XCMD — ДОРАБОТКИ СУЩЕСТВУЮЩИХ ФУНКЦИЙ
Дата: 12 ноября 2026 года

НАЗНАЧЕНИЕ

Единый список из 30 доработок для передачи агенту. Он составлен по результатам
изучения исходников Double Commander, Far Manager, Midnight Commander и muCommander.
Приоритеты обновлены по указаниям пользователя.

Перед реализацией сверить описания текущего поведения с актуальным кодом xcmd:
проект развивается параллельно. Соблюдать AGENTS.md, принятые решения проекта,
дизайн-систему и требования к проверкам без видимых окон.

ПРИОРИТЕТЫ

P1 — реализовывать в первую очередь.
P2 — следующие улучшения повседневного удобства.
P3 — низкий приоритет, редкие случаи и необязательные улучшения.

Всего: 30 пунктов; P1 — 6, P2 — 16, P3 — 8.

Пункты P1:
OPS-01 — Сохранение метаданных при копировании.
OPS-02 — Retry для конкретного файла после ошибки.
PANEL-01 — Суммарный размер отмеченных файлов в статусе.
VIEW-01 — Следить за концом растущего файла.
CMD-01 — Дополнение путей и имён по Ctrl+Space.
CMD-02 — Поиск команд в истории по введённому префиксу.

Состояние реализации, 12 ноября 2026 года:
Все шесть пунктов P1 и PANEL-04 реализованы в версии для проверки.
Дополнительно реализовано создание файла с открытием в редакторе по Shift+F4.
Проверки этой пачки: priority-* в tests/Xcmd.Probe/Scenarios/PriorityBatchScenarios.cs.
Это этап обратной связи; полная финальная проверка и коммит выполняются после
приёмки поведения. Пункты ниже сохранены как исходные требования и приоритеты.

Изменения приоритетов относительно исходного списка:
— проверка свободного места перед записью: P1 → P3;
— суммарный размер отмеченных файлов в статусе: P2 → P1;
— слежение за концом растущего файла: P2 → P1;
— дополнение путей и имён по Ctrl+Space: P2 → P1;
— поиск команд по введённому префиксу: P2 → P1.
Остальные приоритеты сохранены.


1. ФАЙЛОВЫЕ ОПЕРАЦИИ И ОЧЕРЕДЬ

OPS-01. [P1] Сохранение метаданных при копировании

Сохранять атрибуты Hidden, ReadOnly, System и применимые временные метки, включая время создания. Определить явную политику для прав доступа и дополнительных NTFS-потоков: что переносится, что наследуется от назначения и как сообщать о невозможности сохранить данные. На момент исследования в xcmd явно переносилось только время изменения. Образец: Far отдельно обрабатывает атрибуты, права и дополнительные потоки.

Источники: FAR-COPY.


OPS-02. [P1] Retry для конкретного файла после ошибки

Добавить повторную попытку для текущего файла рядом с действиями «Пропустить», «Пропустить остальные такие ошибки» и отменой операции. Сценарий: пользователь закрыл программу, освободил заблокированный файл и продолжил задачу. На момент исследования xcmd фиксировал ошибку и переходил дальше. Образцы обработки ошибок: Midnight Commander и Far.

Источники: MC-ERROR, FAR-COPY.


OPS-03. [P2] Пауза, продолжение и пропуск текущего файла

Добавить паузу и продолжение текущей операции, а также отдельное действие «Пропустить текущий файл». Это позволяет временно освободить диск или пропустить один огромный файл, сохранив остальную задачу. Обе панели должны оставаться доступными. Образцы: Midnight Commander и muCommander.

Источники: MC-OP-DIALOG, MU-PROGRESS.


OPS-04. [P2] Дополнительные правила разрешения конфликтов

Добавить явно выбираемые правила «Заменять только более старые файлы» и, опционально, «Не заменять непустой файл пустым». Сохранить существующие Skip, Rename, Replace, сравнение размеров и времени, а также применение решения ко всем соответствующим конфликтам текущей операции. Образцы дополнительных правил: Midnight Commander, Far и muCommander.

Источники: MC-OP-DIALOG, FAR-COPY, MU-COLLISION.


OPS-05. [P3] Проверка свободного места перед записью

Проверять доступное место до начала записи большого файла. Учитывать временную копию, которую xcmd создаёт перед безопасной заменой: даже замена существующего файла того же размера может требовать дополнительного места. При нехватке места предложить понятные варианты продолжения. Образец: Double Commander. Приоритет по решению пользователя понижен до P3.

Источники: DC-COPY.


OPS-06. [P3] Изменение порядка ожидающих задач

Добавить действия «Выполнить следующей» и «Переместить в конец» для ожидающих задач. Это позволяет поставить маленькую срочную копию перед следующей большой задачей. Образец: менеджер очередей Double Commander.

Источники: DC-QUEUE.


2. ПАНЕЛИ, ВЫДЕЛЕНИЕ И НАВИГАЦИЯ

PANEL-01. [P1] Суммарный размер отмеченных файлов в статусе

Показывать суммарный размер отмеченных файлов рядом с существующим количеством элементов. Для каталогов использовать уже рассчитанные размеры и сохранять явный признак неполного подсчёта. Изменение выделения не должно запускать тяжёлый рекурсивный обход или задерживать интерфейс. Сопутствующая идея исходного списка — показывать свободное место на диске. Основная задача P1 здесь — сумма размеров отмеченных файлов; проверка места перед записью описана отдельно в OPS-05 и имеет P3. Образец: статус панели Midnight Commander. Приоритет суммы размеров повышен пользователем до P1.

Источники: MC-PANEL.


PANEL-02. [P2] Backspace редактирует запрос быстрого поиска

При активном быстром поиске по имени Backspace должен удалять последний символ запроса и обновлять совпадения, сохраняя режим поиска. На момент исследования Backspace сбрасывал поиск и затем попадал в обычную обработку перехода к родительскому каталогу. Образец: Midnight Commander.

Источники: MC-PANEL.


PANEL-03. [P2] Восстановление последнего выделения

Добавить отдельную команду восстановления последнего множества отмеченных элементов после случайного снятия отметок или Escape. Образец: SaveSelection и RestoreSelection в Far.

Источники: FAR-PANEL.


PANEL-04. [P2] Контекстное меню Windows для отмеченной группы

На отмеченном элементе вызывать меню для всей отмеченной группы. На другом элементе открывать меню одного файла с сохранением существующих отметок. На момент исследования Windows получала только путь текущего элемента. Для наборов из разных каталогов в панели результатов поиска отдельно определить поддерживаемое поведение оболочки. Образец группового вызова: плагин EMenu в Far.

Источники: FAR-EMENU.


PANEL-05. [P2] Копирование имён и полных путей как текста

Добавить отдельные команды «Копировать имена» и «Копировать полные пути» для отмеченных файлов. Результат — текстовый список для сообщения, документа или скрипта. Сохранить существующее копирование текста командной строки. Образцы: muCommander и Far.

Источники: MU-COPY-PATHS, MU-COPY-NAMES, FAR-PANEL.


PANEL-06. [P2] Назад и вперёд по переходам между каталогами

Добавить прямые команды назад и вперёд с восстановлением каталога, курсора и прокрутки. Поддержать подходящие горячие клавиши и боковые кнопки мыши. Существующее окно истории сохранить. Образцы истории переходов: Double Commander и Midnight Commander.

Источники: DC-HISTORY, MC-PANEL.


PANEL-07. [P3] Кликабельные сегменты пути

Дать возможность перейти к любому родительскому каталогу нажатием на сегмент пути, сохранив компактность заголовка. Образец muCommander: удержание Ctrl в течение 250 мс временно превращает путь в кликабельные сегменты. Задержка предотвращает мигание при обычных сочетаниях клавиш. Для xcmd способ показа нужно согласовать с дизайн-системой и компактным Git-статусом.

Источники: MU-LOCATION.


PANEL-08. [P3] Выделение по расширению, маске и инверсия

Добавить команды выделения по расширению текущего файла, по маске и инверсию выделения. Сценарии: «все картинки» или «всё кроме архивов». Сохранить быстрый поиск по имени как отдельный режим. Расширенное выделение в проекте сознательно отложено; приоритет остаётся низким. Образцы: Far и Midnight Commander.

Источники: FAR-PANEL, MC-PANEL.


3. ПОИСК И ПАНЕЛЬ РЕЗУЛЬТАТОВ

SEARCH-01. [P2] Несколько масок и явные исключения

Поддержать несколько включающих масок и отдельные исключения. Например: включить *.cs;*.fs, исключить *.g.cs. Это дополняет существующие gitignore-правила и отложенные области поиска конкретным намерением пользователя. Образец: составные включающие и исключающие маски Far.

Источники: FAR-MASK.


SEARCH-02. [P2] Поиск только в отмеченных папках и файлах

Позволить использовать отмеченные элементы панели как область существующего поиска. Сценарий: отметить несколько каталогов и искать только внутри них. Область поиска должна быть явно видна. Образец: поиск по выделению в Double Commander.

Источники: DC-SEARCH.


SEARCH-03. [P2] Ограничения по размеру, дате и глубине

Добавить свёрнутую область дополнительных параметров: диапазон размеров, диапазон дат изменения и глубина обхода. Сценарии: «большие файлы за неделю» или «только текущая папка». Сохранить простой основной сценарий без обязательной настройки. Образец: параметры поиска и шаблоны Double Commander.

Источники: DC-SEARCH, DC-TEMPLATE.


SEARCH-04. [P2] Все совпадения внутри файла

Добавить показ всех вхождений с номерами строк, сохранив быстрый режим первого совпадения на файл. На момент исследования xcmd возвращал только первое совпадение файла. При переносе результатов в файловую панель оставлять уникальные файлы, чтобы несколько вхождений не дублировали файловые операции. Образец переключателя First hit: Midnight Commander.

Источники: MC-SEARCH.


SEARCH-05. [P3] Именованные поисковые шаблоны

Добавить сохранение и загрузку именованного набора параметров: маски, текст, исключения, ограничения и остальные опции. Определить возможность сохранения области поиска вместе с шаблоном. История отдельных строк в xcmd уже существует. Образец: Double Commander.

Источники: DC-TEMPLATE.


SEARCH-06. [P3] Убрать элемент из результатов без удаления файла

Добавить отдельную команду «Убрать из результатов» для ручной сборки рабочего набора. Команда изменяет список результатов, сохраняя исходный файл. Обычный Delete в файловой панели должен сохранить существующее значение удаления файла. Образец: отдельное действие удаления из списка в Double Commander.

Источники: DC-SEARCH.


4. ПРОСМОТРЩИК

VIEW-01. [P1] Следить за концом растущего файла

Добавить режим слежения за концом файла для просмотра логов с автоматическим показом дописанных данных. При прокрутке вверх приостанавливать слежение, позволяя читать старые строки; предусмотреть явное возобновление. Корректно обрабатывать уменьшение или обрезку файла. Обновления должны работать в фоне. Образец: Far отслеживает изменение размера и отдельно обрабатывает уменьшение файла. Приоритет повышен пользователем до P1.

Источники: FAR-VIEW.


VIEW-02. [P2] Позиция, кодировка и режим отдельно для каждого файла

Запоминать позицию чтения, горизонтальную позицию, кодировку, режим отображения и перенос строк для каждого файла. После закрытия и повторного F3 продолжать чтение с сохранённого места. Образец: сохранение позиции и настроек просмотра в Far.

Источники: FAR-VIEW.


VIEW-03. [P2] Перейти к строке, смещению или проценту файла

Добавить прямой переход к строке текста, байтовому смещению или процентной позиции файла. Это полезно для логов и больших бинарных файлов. Образцы: переход к строке в Double Commander; смещения, проценты и относительные переходы в Far.

Источники: DC-VIEW, FAR-VIEW.


VIEW-04. [P2] Дополнительные режимы поиска в просмотрщике

Добавить учёт регистра, целые слова, регулярные выражения и поиск последовательности hex-байтов. Сохранить простой основной поиск и существующие команды перехода между совпадениями. На момент исследования поиск просмотрщика был проще поиска по файлам, а в Hex выполнялся поиск текстовых байтов. Образец: Far.

Источники: FAR-VIEW.


VIEW-05. [P2] Масштаб и перемещение изображения

Добавить масштаб 100%, увеличение, уменьшение и перемещение увеличенного изображения. Сохранить вписывание в окно как доступный режим. Цель — удобно рассматривать мелкие детали и скриншоты. Образец: управление масштабом и размещением изображения в Double Commander.

Источники: DC-VIEW.


5. КОМАНДНАЯ СТРОКА

CMD-01. [P1] Дополнение путей и имён по Ctrl+Space

Реализовать дополнение путей и имён файлов по Ctrl+Space с корректной обработкой кавычек и пробелов. В продолжение этого механизма предусмотреть дополнение переменных окружения и программ из PATH. Показывать варианты и позволять выбрать подходящий с сохранением черновика. Ctrl+Space — выбранное пользователем сочетание; существующий Tab должен продолжать переключать панели. Сохранить модель быстрого запуска через Windows ShellExecute. Образец источников дополнения: Far. Приоритет повышен пользователем до P1.

Источники: FAR-CMD.


CMD-02. [P1] Поиск команд в истории по введённому префиксу

Если в строке введён префикс, позволить искать или перебирать соответствующие команды истории. Например, после ввода git показывать подходящие прошлые команды с сохранением незавершённого черновика. Выбор из истории сам по себе не запускает команду. Образец: поиск похожей команды в Far с выделением дописанного окончания. Приоритет повышен пользователем до P1.

Источники: FAR-CMD.


6. АРХИВЫ

ARCHIVE-01. [P2] Умная папка распаковки

Добавить распаковку в отдельную папку с именем архива и умный режим: создавать такую папку, когда на верхнем уровне несколько элементов; учитывать уже имеющуюся общую корневую папку, чтобы не получать лишнюю вложенность. Цель — не рассыпать содержимое архива по каталогу назначения. Образец: отдельная папка и Smart Extract в Double Commander.

Источники: DC-EXTRACT, DC-SMART-EXTRACT.


ARCHIVE-02. [P3] Ввод пароля для просмотра и извлечения

Добавить диалог пароля при обращении к зашифрованным элементам поддерживаемого архива. Предусмотреть повторную попытку после неверного пароля и отмену с сохранением текущей панели. Образец отдельного диалога: muCommander.

Источники: MU-PASSWORD.


ARCHIVE-03. [P3] Проверка архива без распаковки на диск

Добавить отдельную команду «Проверить архив»: проверить читаемость и целостность данных там, где формат поддерживает такую проверку, без создания распакованных файлов в каталоге назначения. Показывать прогресс, результат и ошибки; поддержать отмену. Образец: Test Archive в Double Commander.

Источники: DC-TEST-ARCHIVE.
