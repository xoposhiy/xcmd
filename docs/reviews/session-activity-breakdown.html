What this view shows

Counting rules and sample source

One row counts a completed tool call once. A search target, a Git diff and a script invocation each have their own evidence. Only a confirmed file read contributes to the Reads column. Command exit codes and patch completion are shown as recorded.

Tool time adds recorded call durations, including overlapping calls. Elapsed time runs from the first start to the last completion in this sample. No time or token share is assigned to individual commands inside a single call.

The anonymized commands, path actions and line ranges come from the reviewed Point Taken corpus. Durations come from the matching local transcript records. This sample uses local evidence. A production view should mark any Luna inference beside the corresponding action. Corpus notes
