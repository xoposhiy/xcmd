# Epics and user stories

This is the LivingDoc for Xcmd's product and developer needs. Read epics in
the order below and stories in their file order. Later stories can rely on the
context established earlier.

Epics describe broad, stable needs. Each story states a more specific need.
Explicit implementation decisions, when recorded, live in a separate section
under the story and can change more often. See [story maintenance](../processes/stories.md)
for the format, semantic IDs and source mapping conventions.
