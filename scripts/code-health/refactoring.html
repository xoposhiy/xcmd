Measurement

Both snapshots use Roslyn Metrics 5.6.0 and direct @implements links from authored C# in Xcmd's three production projects.

Branching sums the cyclomatic complexity above one for each Roslyn member. Weighted complexity multiplies branching by the number of linked stories beyond the first.

File width counts Unicode characters, including comments and whitespace, with line endings counted as one character. Each story has one unit of width on the scattering chart.

Area adds each point’s value times its width. Tangling and scattering have the same area because each story–file link counts the file’s characters once on each chart.

Each C# file has its own metrics, including files that define parts of a partial class.
