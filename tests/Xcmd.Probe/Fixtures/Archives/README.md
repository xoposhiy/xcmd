# Archive samples

The RAR4, RAR5, 7z and self-extracting 7z samples come from
[SharpCompress 0.50.8](https://github.com/adamhathcock/sharpcompress/tree/0.50.8/tests/TestArchives/Archives).
The upstream MIT license is included in LICENSE.txt.

Tests read these files as archives. Tests never execute the EXE sample or any extracted program.
ZIP, TAR and GZip samples are created in isolated test fixtures.
